Q09Serverless DesignMedium
Your CloudChat Lambda function works fine locally with Flask but in production you get a cold start delay of 3-4 seconds on the first request. What causes cold starts and what is one way to reduce them?
ACold starts are caused by large S3 files. Solution: delete old session files
BCold starts occur when Lambda initialises a new execution environment (container) for the first request after a period of inactivity — downloading code, starting the runtime, and running init code. Solution: Provisioned Concurrency keeps warm environments ready, or reduce package size and init time
CCold starts happen when two users call the function simultaneously. Solution: set concurrency limit to 1
DCold starts happen because Lambda downloads your code on every request. Solution: use a CDN to cache the code
